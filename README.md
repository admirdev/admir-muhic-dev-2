# Admir Muhic - Portfolio

A modern portfolio website built with Vue.js 3, Vite, and Bootstrap.

## Features

- **Vue 3 Composition API**: Modern reactive components
- **Vite**: Fast development and optimized builds
- **Bootstrap 5**: Responsive design with Bootstrap components
- **Pinia**: State management for Vue applications
- **Vue Router**: Client-side routing with nested routes
- **SCSS**: Custom styling with Sass
- **GitHub Actions**: Automated deployment to GitHub Pages

## Tech Stack

- **Frontend**: Vue.js 3, Vite, Bootstrap 5, SCSS
- **State Management**: Pinia
- **HTTP Client**: Axios
- **Build Tool**: Vite
- **Deployment**: GitHub Pages

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/admir-muhic-dev-2.git
cd admir-muhic-dev-2
```

2. Install dependencies

```bash
npm install
```

3. Start development server

```bash
npm run dev
```

4. Build for production

```bash
npm run build
```

## Project Structure

```
src/
├── components/          # Reusable Vue components
│   ├── bars/           # Navigation components
│   ├── helpers/        # Utility components
│   ├── profile/        # Profile-related components
│   └── projects/       # Project components
├── views/              # Page-level components
├── router/             # Vue Router configuration
├── stores/             # Pinia stores
├── services/           # API services
├── styles/             # SCSS stylesheets
└── assets/             # Static assets
```

## Deployment

The project is configured for automatic deployment to GitHub Pages using GitHub Actions. Push to the `main` branch to trigger deployment.
